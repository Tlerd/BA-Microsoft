# Glossary: CourtBook

| Term | Definition | Synonyms to avoid |
|---|---|---|
| Booking | A reservation of one court for 1 or 2 consecutive hours by one Player. | Reservation, order |
| Booking code | The code that identifies a confirmed Booking. The system sends it by email. | Ticket, reference |
| Club Manager | The person who runs the club and blocks courts for maintenance. | Admin, owner |
| Court | One of the 6 badminton courts of the club. | Field, room |
| Payment Provider | The service that tells the system that a QR bank transfer arrived. | Bank, gateway |
| Player | A person with an account who books a Court. | User, customer, member |
| Slot | One hour on one Court. | Time block, session |
